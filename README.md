# 闸对

中文名：**闸对** · 前缀 `gatetwin` · 端口 **6500 / 11500**

## 骨架

**刷卡点装载 → 同卡进站出站成对物化 → 缺腿/异向/超时旁路 → 行程账与刷卡点互证**

皮：地铁/公交闸机刷卡。去皮是 **OD 成对管道 + 开腿态 + 旁路 + 行程贯验**，不是票务售票 CRUD、不是乘车码业务页、不是日结封账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6500
# 刷卡流 → 灌「成对样例」→ 看开腿账/行程账 → 再灌「缺腿超时样例」「出站孤儿样例」→ 行程贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 刷卡点 | 带卡号/站点/方向/事件时的进出闸事件 |
| 开腿账 | 已进站尚未出站的在途开腿 |
| 行程账 | 进站+出站成对后的正式行程 |
| 旁路匣 | 缺腿超时 / 出站孤儿 / 重复进站等 |
| 行程贯验 | 成对刷卡 ↔ 行程笔数 ↔ 旁路命运互证 |

## 同站裁决（已落主链路）

全局唯一架构：**以站距零禁对为准（口径甲）**。进站站点键 == 出站站点键（站距零）时：

- 禁止写行程账——同站 A→A 在库中不存在行程行（与「短途同站可对」口径的库态可区分）；
- 在途开腿关闭为「已旁路」，进站/出站两笔刷卡命运同票落「已旁路」；
- 旁路匣钉 `原因=同站禁对`，载荷带 `站距零=1` 与旁路键；
- 写闸与开腿关闭在同一 `BEGIN IMMEDIATE` 事务内同成败，并发装载串行化，杜绝旁路证与行程行双落。

只读裁决接口：`GET /api/同站裁决?进站事件编号=&出站事件编号=`（或 `进站站=&出站站=`），
返回进站站、出站站、站距零标记、命运、行程或旁路键、valid、架构。
